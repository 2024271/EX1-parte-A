# Memória Descritiva

Este seguinte projeto tem como objetivos a criação do quadro de Mondrian.
Para este trabalho foi necessário medir o quadro usando um programa vetorial sugerido pelo professor como uma opção gratuita (inkscape), para assim poder recriar o quadro de maneira mais fiel possível.
Para conseguir escolher as cores utilizei um conta gotas-digital e pedi ajuda á inteligência artificial para me identificar a cor para ser o mais fiel possível.
Para terminar, para criar as medições pedi ajuda á inteligência artificial para me explicar o que cada coordenada fazia, sendo por exemplo: rect(x, y, largura, altura), sendo x e y o que define a posição do retângulo em relação ao canto superior esquerdo do ecrã, sendo x a distância da lateral esquerda e y a distância do topo da imagem. Já na line(x1, y1, x2, y2), sendo x1 e y1 as coordenadas do ponto inicial da linha e x2 e y2 o ponto final da linha. Para fazer as cores basta misturarmos 3 valores que representão o "RGB": Red, Green and Blue.
